据[百度杀毒频道](http://shadu.baidu.com)报道，昨天，百度联合金山公司宣布[百度安全中心](http://an.baidu.com)正式上线。据介绍，百度安全中心是一款保障网民个人信息安全的网页版软件，兼具免费病毒查杀、系统安全检测、系统漏洞修复、恶意软件清理等多项功能，提供了免费的专业在线杀毒服务。新上线的百度安全中心启用了全新的独立域名，其功能其功能几乎完全涵盖了包括业内主流安全服务。

由于百度安全中心和奇虎的360安全卫士的功能很类似，因此我就参照[奇虎360安全卫士](https://www.williamlong.info/archives/583.html)对百度安全中心进行了一下简单的功能评测和对比。

![百度安全中心评测](/upload/1256_1.jpg)

**需要安装ActiveX控件**

与奇虎360safe不同的是，百度安全中心的免费检测和在线杀毒都需要安装ActiveX控件，并没有提供客户端下载。这和通常的安全产品的使用习惯有点不符合，因为客户端软件可以保证在不联网的情况下也可以杀毒，当系统出现安全漏洞的时候，联网会使得安全漏洞变得更为危险，带来更多不可预知的风险，因此，百度应该提供类似360safe那样的客户端软件才更为方便和安全。

**界面较为直观**

![百度安全中心评测](/upload/1256_2.jpg)

免费检测的界面采用“打分”的方式来表明系统的安全性，非常直观，同时提供“一键修复”的功能，可以快速修复系统漏洞，操作简便。在查询过程中发现了很多360safe所没有检测到的漏洞，功能看起来还算比较强大。

**支持Windows Server 2003操作系统**

![百度安全中心评测](/upload/1256_3.jpg)

我们知道，服务器的安全性其实比个人电脑的安全性更重要，可惜的是360safe不支持2003的系统漏洞修复，而百度安全中心的系统漏洞修复却支持Windows Server 2003，这点百度做的比奇虎要好。从使用效果上来看，百度安全中心的确可以检测并下载安装到最新的Windows Server 2003的安全补丁。

![百度安全中心评测](/upload/1256_4.jpg)

**在线杀毒**

![百度安全中心评测](/upload/1256_5.jpg)

在线杀毒使用的是金山毒霸的程序进行检测的，比较令人迷惑的是，在“系统安全检测”里面已经没有恶意软件和系统漏洞了，而“在线杀毒”却又检查出了恶意软件和系统漏洞，可能两者使用的并非相同的代码。

另外，金山提供的这个在线杀毒并非完全免费的产品，每天只在限定的时间免费，免费时段为：00：00—09：00，11：00—19：00，23：00—24：00，其他时段杀毒则需要收费。

**浏览器修复**

![百度安全中心评测](/upload/1256_6.jpg)

有趣的是，在浏览器修复选项中，360safe的浏览器插件被百度视为“分析中”而并非“安全”，看来“同行是冤家”真是永恒的真理啊。

总的来说，百度安全中心支持Windows Server 2003是其一大亮点，但是主要的的功能并没有360safe多，杀毒功能并没有完全免费，也没有离线软件和[ARP防火墙](https://www.williamlong.info/archives/1090.html)，百度要在这方面有所突破，还需要再接再厉了。
