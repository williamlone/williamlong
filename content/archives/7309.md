GitHub CLI (gh) 是 GitHub 官方推出的开源命令行工具，旨在将 GitHub 的核心功能（如拉取请求、议题、仓库管理、Actions 等）直接带入终端。 并且还提供了用于在同一台设备上管理多个 GitHub 账号并快速切换活跃身份的功能。

**一、安装 GitHub CLI**

Windows安装：winget install GitHub.cli

MacOS安装：brew install gh

Linux安装：sudo apt install gh

**二、多账号管理**

对于拥有个人账号和工作账号的开发者，gh 提供了原生的多账号切换支持。

查看当前状态：gh status

输入gh status用来查看订阅的所有仓库中在 GitHub 上的当前工作的详细信息。

查看账号状态：gh auth status

输入gh auth status可查看当前所有配置的账号信息，包括活跃状态、Git协议和令牌权限范围。

添加新账号：gh auth login

使用gh auth login命令可添加新账号，系统会自动检测现有账号并提示通过浏览器OAuth流程完成认证。

切换活跃账号：gh auth switch

使用gh auth switch命令提供交互式账号切换，执行后所有后续操作将使用选定账号的凭证。

设置凭据：gh auth setup-git

把 Git 的凭据助手（credential helper）设置成 GitHub CLI（gh），以后用 HTTPS 协议执行 git push / git pull 的时候，Git 不再去 Windows 凭据管理器拿账号密码，而是调用 gh，读取 gh 当前激活账号的 Token。

退出登录状态：gh auth logout

使用gh auth logout命令提供退出登陆，如果本地登录了多个账号，CLI 会弹出一个提示框，让选择要退出的具体账号。

查看帮助文档：gh help

使用gh help查看某个具体命令的帮助。
