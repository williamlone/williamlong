今天收到微软Windows Live小组发来的邮件，说[Windows Live Spaces](https://www.williamlong.info/archives/582.html)服务已经升级，升级后的 Windows Live Spaces以全新的面貌展现，用户可以体验到更加完善的Windows Live功能。具体的更新内容如下：

照片现在从 Windows Live Spaces 移到了 Windows Live 照片中，用户可以使用更加丰富、易用的工具来管理您的照片。

面貌一新的 Spaces 外观更加整洁、简练，不但新增了大字体的功能，而且除了主页以外的其他网页上都没有横幅广告。 （我观察自己的Spaces，首页上其实也没有广告横幅）

用户的共享空间个人资料现在是 Windows Live 个人资料的一部分，更加便于管理。

用户的共享空间公告板现在专门记录共享空间博客更新和留言。在用户的 Windows Live 主页上还有更为完整的公告板，记录好友的最新动态。

现在，[Windows Live](http://home.live.com/)的主页更像一个SNS网站了。

我个人的Windows Live Spaces地址是： `http://williamlong.spaces.live.com`
