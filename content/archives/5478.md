9月27日，Cloudflare 官方博客宣布推出域名注册服务，承诺只收取成本费，不赚取利润，且承诺不会逐年加价。

域名的生态环境主要由两类机构组成，一是域名的注册管理机构 Registry，例如管理 .com 与 .net 的 Versign，或是管理 .biz 的 NeuStar，其次就是面向使用者的域名注册服务机构 Registrar，由 Registrar 向 Registry 取得销售特定域名的权限。

一般来说，Registry 向 Registrar 收取的费用是固定的，但 Registrar 向使用者收取的费用则不一定，有些在第一年提供较低的价格，但续费价格却不断往上飙涨，最好的情况是原来的两倍，最多的情况可能甚至达到20倍，还有些 Registrar 会不断向使用者推销其它服务，也有些收取费用昂贵的 Registrar 无法提供最初所承诺的安全性。

Cloudflare 表示，Registrar 要做的事情只是把某个域名登记在使用者名下，传送指令到一个 API 就能办到，Registrar 根本无法提出加价的正当理由。

这使得 Cloudflare 决定提供成本价的域名注册服务。举个例子，掌管 .com 的 Verisign 每年向 Registrar 收取 7.85 美元的费用，而 ICANN 则针对每个出售的域名收取 0.18 美元的费用，因此，当 Cloudflare 用户向 Cloudflare 注册 .com 的域名时，每年只要缴交 8.03 美元的注册费用，完全以成本价提供给用户。

目前 Cloudflare Registrar 服务只对旗下客户开放，且初期只能将已有的域名迁移到 Cloudflare Registrar，尚未开放新域名的注册，Cloudflare 打算在未来几周为客户发出邀请函，顺序是依照客户加入 Cloudflare 时间的早晚。

在安全性上，Cloudflare 则承诺将支持双因素验证，默认会锁定客户所申请的域名，也将自动启用最佳实践的安全服务。

根据 Datanyze 的统计，Cloudflare 目前为全球第三大内容分发网络提供商（Content Delivery Networks, CDN），市场占有率为 11.13%，落后 Amazon CloudFront 的 47.48% 与 jsDelivr 的 12.76%。
