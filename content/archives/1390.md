几天前，我发现我的Outlook Express开始无法接收Live Hotmail的邮件，我以为先前报道的“[微软Outlook Express将无法访问Hotmail](https://www.williamlong.info/archives/1321.html)”要提前实现了，后来通过Web登录Hotmail后，发现微软发来的邮件，说并没有完全停止Outlook Exxpress对Live Hotmail的访问支持，微软还在研究替换解决方案，以便在6月30日之后依旧可以通过Outlook Express访问Hotmail。

附随IE安装的Outlook Express具有很大的装机量，和Windows Live Mail相比，我很喜欢OE的快捷和简单，OE的地址簿管理也很不错，感觉比Live Mail的地址簿好用（当然Live Mail的地址簿是网络存放的，原理不同）。另外我的Live Mail的性能感到有点怀疑，Outlook Express将所有邮件都压缩为一个文件，而Live Mail则每个邮件时一个单独的文件，当邮件非常多的时候，会产生海量的文件，这不会引起性能问题吗？

当然，Live Mail的反垃圾邮件功能是Outlook Express所没有的，Live Mail和Live系列产品的集成和结合也很紧密，然而无法否认的是，很多人还是喜欢Outlook Express的简单，如果微软打算停止开发Outlook Express的工作，或者把这项工作置于“维持工程”模式，那么随着广大用户的需求，微软未来可能还会改变最初的决定。

附：微软发来的邮件：“Outlook Express 服务变更”

尊敬的 Microsoft Outlook Express 用户：

您可能已经收到了我们的电子邮件，通知您 Microsoft 计划停用 Outlook Express 用于访问 Windows Live Hotmail 的 DAV 协议。由于用户反映需要更多的时间对替代解决方案进行评估，因此我们决定推迟停用 DAV.同时，我们正在研究通过 Outlook Express 访问 Windows Live Hotmail 的其他替代解决方案。这意味着，如果您使用 Outlook Express 访问 Windows Live Hotmail 帐户，您在之前宣布的 6 月 30 日截止日期之后还可以继续使用。我们推出其他共享计划时一定会通知您，并为您留出足够的时间，以确保您将来顺利过渡。

此外，随时欢迎您使用 Windows Vista 或 Windows XP 的 Outlook Express 用户下载和使用我们的新一代免费电子邮件客户端 Windows Live Mail，它在 Outlook Express 基础上提供了更多的功能。您可以从 http://get.live.com/wlmail/overview 下载新客户端。

我们感谢您提供反馈，并欢迎您继续提供。

此致，Windows Live Mail 团队
