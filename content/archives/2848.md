据谷歌官方博客[报道](http://googleblog.blogspot.com/2011/10/fall-sweep.html)，谷歌决定关闭社交网络服务Google Buzz和其他一些产品，并将一些社交产品中的部分功能进行整合。

在未来的几周内，Google Buzz和其API将被关闭，其功能将由Google+替代，届时用户将无法在Buzz中添加新的内容，不过用户可继续在其个人资料中看到Google Buzz的内容，并通过Google Takeout服务将Buzz的数据导出。

Jaiku将在2012年1月15日关闭，届时Google将提供数据导出工具。

Google Code Search也将在2012年1月15日关闭，这个为程序员提供开放源码搜索的服务被关闭实在令人不解。

iGoogle的社交功能将被删除，那些功能将被整合到Google+中，2012年1月15日之后，用户依旧可以使用没有社交功能的iGoogle应用。

另外，Google Labs（谷歌实验室）也将在今天关闭。

![谷歌将关闭Google Buzz等产品](/upload/2848_1.jpg)

Google关闭了以上的很多产品，主要是为了继续将资源和开发重点放在Google+上，驱使用户从这些产品转移到Google+上，目前Google+服务的注册用户人数已达4000万。

Google的这些产品中，我用的最多的是Google Buzz和Google Code Search，我对Google Code Search被关闭表示不解，并且目前还没找到类似的工具。对于Google Buzz，目前用的也不多了，因为上面人太少，希望Google Buzz关闭之后，Gmail能在中国变得稳定一些，毕竟Gmail比Buzz重要的多，目前Gmail在中国访问困难实在很影响中国用户的日常工作和生活。

尽管Google关闭了这么多服务很大程度上是为了Google+，但是目前Google+的运营情况并不太理想，[流量大幅下滑](https://www.williamlong.info/archives/2791.html)，API功能也不太理想，甚至连Google的工程师Steve Yegge也对Google+进行了[一些批评](https://plus.google.com/112678702228711889851/posts/eVeouesvaVX)，关闭上述那些产品，也未必能对Google+的现状起到良好的改善作用。
