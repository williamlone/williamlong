自2026年1月起，一款名为OpenClaw（网友俗称“小龙虾”）的开源AI智能体在国内外社交媒体爆火，并衍生出收费安装服务。北京、上海、深圳等地的不少企业放出了“OpenClaw开发工程师”等岗位，其要求不限于“熟悉OpenClaw工具，有实际部署经验”等。

据了解，OpenClaw是由奥地利退休程序员Peter Steinberger发起的开源项目，一个能让大模型获得本地操作系统权限的开源智能体框架，可让AI自己执行Shell命令、操作文件系统，实现“本地代理主权”。有网友表示，对于普通人来说，OpenClaw相当于拥有一个24小时在线的私人电脑助理。

下面就简单介绍一下Mac电脑安装OpenClaw的教程。

1、安装 Homebrew

Homebrew是Mac系统上的软件包管理工具，这里的软件并不是指从AppStore或从网上下载的dmg文件，而是开发所需要用的一些工具软件，只需要一个命令， 安装和卸载它们非常方便。

对于国内用户来说，可以使用下面的命令来安装：

/bin/zsh -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"

2、安装git

使用下面的命令安装：

brew install git

3、安装Node.js

使用下面的命令安装：

brew install nodejs

4、安装OpenClaw

使用下面的命令安装：

sudo npm install -g openclaw@latest

或者这个命令也可以

curl -fsSL https://openclaw.ai/install.sh | bash

跟着配置向导走，安装完成后，会自动弹出一个配置向导。配置向导走完后，OpenClaw 会自动作为后台服务启动。你可以用下面的命令确认它在正常运行：

openclaw gateway status

然后打开浏览器，访问：

http://127.0.0.1:18789/

这就是 OpenClaw 的控制面板，你可以在这里跟你的 AI 助手聊天了。
