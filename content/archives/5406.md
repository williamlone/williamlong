谷歌、Facebook、微软和Twitter今日联合发布一个新的数据转移标准，为消费者在各平台之间转移数据提供一种新方式。

这项新标准被称为“数据转移项目”(Data Transfer Project)，其中谷歌在一份声明中称，该项目允许用户直接从一种服务(一个平台)向另一种服务(另一个平台)转移数据，而无需下载后再重新上传。

该系统当前版本支持照片、邮件、联系人、日历和任务等数据，在谷歌、微软、Twitter、Flickr和Instagram等公开可用API中提取。

当前，用户可能正通过其他方式来转移上述平台上的数据，但谷歌、Facebook、微软和Twitter希望该项目能更进一步，从而替代传统的API。

这些公司表示：“将来，数据转移需要更直观、更灵活、更开放。我们希望该项目能在任意两项服务之间建立起直接的连接，以便于数据的直接转移。”

谷歌产品经理格雷格·费尔(Greg Fair)称：“人们拥有数据，他们希望从一款产品直接转移到另一款产品上。但目前，他们还不能轻松地做到这些，这还是一个尚未真正解决的问题。”

其中很多代码库都包含可以将私有 API 转换成互操作性迁移的「adapter」，比如，使得Instagram的数据可传输至Flickr，反之亦然。在这些 adapter 中，工程师还构建了一个系统来加密传输数据，为每次数据迁移发布前向保密密钥（forward-secret key）。值得注意的是，该系统专注于一次性迁移，而不是很多 API 支持的连续互操作。

项目开源代码：https://github.com/google/data-transfer-project
