还记得吗？就在 2012 年 2 月 29 日，巴塞罗那这座古老城市突然之间变得万众瞩目，因为微软会在 2012 年的世界移动通讯大会上发布备受期待的 Windows 8 Consumer Preview（下称 W8CP）。虽然今天微软就会隆重发布 Windows 8 Release Preview（下称 W8RP），但是在下载时，各位看官不妨看看这篇文章，了解一下 Release Preview 是如何一路走来？

Windows 8，这款操作系统将被微软寄予厚望，它将支持多种设备、整合云的技术、提供新的体验，这是一次基于 Windows 7 速度和可靠性核心本质的重塑和创新，Windows 从此破茧重生。

在 Windows 8 CP 发布后，热度逐渐沉寂下来。微软官方博客 Building Windows 8 （下称 B8）率先打破这一寂静，发表博文《[缩放至不同屏幕](http://blogs.msdn.com/b/b8_cn/archive/2012/03/29/10289101.aspx)》，重申 Windows 8 支持屏幕的广泛性，里面提到 Metro 应用最低分辨率为 1024\*768、支持全部功能的最低分辨率为 1366\*768，系统内置排版控制技术，应用可以自动适应屏幕，支持不同像素密度以及自动缩放。

这也使得 Windows 8 成为有史以来支持屏幕类型最广、最多、最完善的操作系统，大到鲍尔默办公室里的巨屏，小到入门用户手头上的小屏，都会是 Windows 8 的舞台。

![从 Consumer Preview 到 Release Preview](/upload/3111_1.jpg)

对于用户而言，Windows 8 提供了高度一致的使用体验，用户可以轻松读取内容，不管他是在用触摸还是鼠标。对于开发人员来说，Windows 8 能够自动根据像素密度进行缩放，支持矢量图形，而且提供强大无比的开发工具，可以轻松支持不同尺寸、不同分辨率、不同像素密度的各种屏幕。

几乎就在同时，著名人物Canouna在其 Twitter 上面提到 Windows 8 将会新增多个版本，例如 Professional Plus（专业增强版）、ARM 等等，这也使得用户对 Windows 8 开始产生浓厚兴趣，热度终于提了上来。

随后，各大网站争相发布关于 Windows 8 的最新消息，包括预言 W8RP 为 8400、发布日期为五月末、六月初等，这体现了广大群众 Windows 8 的无限热情。后来一个重磅消息被曝光，微软将会专门面向中国大陆发行一个特殊版本——China 版，这体现了微软对于中国市场的高度重视。

![从 Consumer Preview 到 Release Preview](/upload/3111_2.jpg)

微软官方博客 B8 发布重要博文《[触控硬件和 Windows 8](http://blogs.msdn.com/b/b8_cn/archive/2012/04/05/windows-8-touch-hardware.aspx)》，指出 Windows 8 将能够在当今的硬件设备上运行，而且表示微软已经确定触控手势，最少要求支持五点触屏，与前相比加强了边缘轻扫体验，创造更佳的触控体验。

之后几天，这个博客继续发表博文，指出 Windows 8 将会支持多种编程语言，另外又说WinRT改进了内存管理，使其可以使其可以使用 API 来访问所需的所有内存，同时在响应速度和完成工作方面，将用户放在首位。

不久之后，各种传闻继续流出，局面变得更加热闹。著名网站 WinUnleaked.tk 撰文指出，微软还为发展中国家提供 Core 版本，接着甚至表示微软将会针对不同的销售国家发行不同语言的版本，即 Single Language（单语言）版本。

消息显示微软将会继续改变软件版本命名方式，例如 Milestone 3 被命名为 Developer Preview，Beta 被命名为 Consumer Preview，RC 被命名为 Release Preview 等等，这样命名突出了受众群体，较之以前更加人性化。而 Windows 8 的 ARM 版本，也被命名为 Windows RT，至此已经确定 Windows 8、Windows 8 Pro、Windows RT 将是三大主要版本。

微软官方博客 B8 再次发布博文，提醒开发人员关于 Metro 应用程序的生命周期问题，并且指出 Windows 8 将会拥有强大的企业功能支持，例如 Windows To Go、DirectAccess、BranchCache、AppLocker、VDI 增强、应用部署等等功能，而且专为企业创造了一个新的管理系统。

到了五月，随着各种 SKU 版本信息被不断证实，大家逐渐把眼光放到了媒体中心。媒体中心自从 Windows XP Media Centre Edition 以来一直都是 Windows 的重要组成部分，不过据消息称，出于成本考虑，微软打算在 Windows 8 中去掉媒体中心，如果用户仍想使用，那么必须付费升级。

微软官方博客 B8 发布重要文章《[重新设计chkdsk和新的 NTFS 健康模式](http://blogs.msdn.com/b/b8_cn/archive/2012/05/17/chkdsk-ntfs.aspx)》，指出微软正在重新设计chkdsk，用来检测以及修复磁盘损坏。另外，微软还会优化系统，减少系统故障，提供一种高效磁盘解决方案。

不久之后，这个博客再次[撰文](http://blogs.msdn.com/b/b8_cn/archive/2012/05/18/windows-8-family-safety.aspx)指出，Windows 8 将会添加一个特殊账号“Children”，这个账号将会完全由父母控制，可以规定上网的时间以及范围。另外，系统还会收集孩子上网内容，生成一份分析报告，提供父母作为设置参考。

![从 Consumer Preview 到 Release Preview](/upload/3111_3.jpg)

还是这个博客，这次[介绍](http://blogs.msdn.com/b/b8_cn/archive/2012/05/25/windows-8-word.aspx) Windows 8 对于多重监视器的完美支持，指出用户可以为不同的监视器选择不同的桌面背景、分辨率以及方向。另外用户可以在不同的监视器下使用不同的任务栏，支持 Metro 界面与传统界面同时工作。紧接着，这个博客撰文解释关于 Metro 应用后台运行的一些细节。里面提到不使用的程序将在后台被挂起，挂起后可以被迅速唤醒并且同步数据。

五月中旬，最具爆炸性的新闻流出。微软在其官方博客 B8 上表示将会[放弃 Aero 磨砂玻璃界面](http://blogs.msdn.com/b/b8/archive/2012/05/18/creating-the-windows-8-user-experience.aspx)，使 Aero 界面能与 Metro 相协调，界面也变得更加简洁明快。这引起了很大争议。用户希望能够瞬间启动 Metro 应用，于是这个博客再次撰文，告知开发者们怎样编写程序，创造一个快速启动体验。

与此同时，各大科技网站也在泄漏关于 Windows 8 的一些信息，例如新的内置应用、新的桌面壁纸等等，到了最近几天，W8RP 简体中文安装镜像已被泄漏，虽然文件遭到破坏，但是许多网友已经克服困难，装上这个版本。

从 Consumer Preview 到 Release Preview，微软官方博客 B8 通过发表多篇博文，详细地讲解了 Windows 8 的各种功能，指明了 Windows 8 的前进方向，为广大开发人员了解 Windows 8 打开一扇窗口。另外，也要感谢各大科技网站，不辞劳苦地提供最新消息，陪伴我们走过这三个月来的历程。

Windows 8 将是一次大的变革，它将颠覆人们原有使用习惯，尽管它有可能不被用户接受。微软一直希望 PC 能有流畅的用户体验，各项应用程序能够互相协作，能够帮助用户简化日常任务，这是一个美化愿景。科技发展日新月异，世界仍在不断前进，Windows 也将不断改变，就让我们一起展望未来美好未来！
