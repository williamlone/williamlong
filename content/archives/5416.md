曾经免费的Google Maps不再免费。Google从7月16日起限制API请求次数，超过限制将收费，并强制要求所有项目必须使用官方的 API key，如果没有API key，地图的质量可能会降级或地图将无法工作。

API key必须关联信用卡，如果超过限制的请求次数，那么Google将会开始从信用卡收费。搜索巨人先向用户免费提供了每月200美元的信用。

Google大幅削减了免费请求次数，从每天2.5万展示减少到每月2.8万次展示，也就是每天展示次数为1000次左右，减少到原来的二十五分之一。

为了避免突然增加的信用卡账单，许多地图项目开始转移到其它地图服务。Openstreetmap项目发表了一篇文章介绍为什么要用 OpenStreetMap。

2018年5月2日Google发文预告，将在7月16日调整收费模式。每位用到Google地图架设服务的开发者，不论是否达到Google地图收费的标准，都得申请API key，并且绑订信用卡卡号。而每位都有每位200美元的免费额度，超过需要付费给Google购买API额度。

早年Google地图以免费的方式进行，从产品角度来看Google地图相当方便，开发者不必太懂地图相关知识，只要手上有地理资料，都可以套在Google地图上面，在Google的新政策下，开发者都需要改变作法。
