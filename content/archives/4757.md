据路透社报道，8月24日Note 7发生“首炸”之后，三星经历了熬人的47天。昨天被美国三大运营商抛弃后，韩国媒体传出三星暂停Note 7生产的消息，现在三星终于有了进一步动作，该公司官方宣布将停止Note 7在全世界的销售，并建议Note7用户停止使用该产品，保持手机关机状态。

三星电子对外表示，将会要求全球的移动运营商和零售合作伙伴停止销售Note 7手机。并要求Note 7用户关机，停止使用，包括持原装手机或已完成更换的用户。

三星电子称，正与美国消费者产品安全委员会（CPSC）合作，调查近期报道的Galaxy Note 7手机问题。

三星电子表示，公司需要对近来出现的替换新手机出现的电池燃烧故障进行调查。将会要求全球的移动运营商和零售合作伙伴停止销售Note 7手机，停止给出现故障的Note 7用户再一次发放Note 7新手机。

在第二次全球召回的消息确认后，Galaxy Note 7产品线似乎已经没有存在的必要，此前路透就曾猜测三星将彻底关闭Galaxy Note 7产品线，现在消息已经证实。彭博和华尔街日报都已经发布快讯消息，称三星因缺陷导致的安全问题永久终止Galaxy Note 7产品线的后续生产和销售。

目前全球所有拥有Galaxy Note 7的用户都正在被通知将设备返回到最初购买的地点，各运营商也已分别发布声明，通知所有Note 7用户更换型号或其它制造商的手机产品。

经过数月的挫折，包括停止销售、换机、召回、诉讼、FAA警告和禁令，三星Galaxy Note 7到今天为止终于迎来了彻底的失败，另有迹象显示，三星正将准备中的下一代产品Galaxy S8发布工作提上日程，以弥补此次重大事件造成的市场空白和损失，进而恢复公司的公众形象，预计S8会迎来双摄像头、新的处理器和更彻底的重新设计。

在这份声明中，三星电子也表示，无论是使用最初的Note 7手机，还是最近新替换的手机，所有的全世界Note 7消费者最好能立刻关机，停止继续使用这款设备。

以下是三星电子周二发布的声明原文：

> 我们正在和美国消费产品安全委员会合作，共同调查最近围绕Galaxy Note 7手机发生的事故，因为消费者的安全是我们工作的重中之重，因此在调查进行期间，三星将会要求全世界所有的移动运营商和零售伙伴，停止Note 7手机的销售和替换。
> 
> 三星将继续和美国消费产品安全委员会、移动运营商以及零售伙伴紧密合作，采取必要措施解决问题。
> 
> 使用最早Note 7或是替换Note 7手机的消费者应该关机，利用目前提供的各种解决方案，其中包括在原购买地进行退款。如果需要更多信息，消费者可以访问如下网址samsung.com/us/n
