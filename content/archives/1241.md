微软早就说要在2月12日使用[自动更新来强行升级浏览器](https://www.williamlong.info/archives/1217.html)，现在时间已经到了，微软开始行动了，今天我的自动更新程序就开始下载庞大的IE7客户端，但是下载速度非常慢，下了快一天了仅仅下载20%多一点，估计要下载很长时间。目前就我博客上的统计数字来看，IE6的用户目前还比IE7多一倍以上。

根据我的Yahoo Stat统计数字来看，昨天访问月光博客的浏览器数据列表如下：

| 浏览器 | 百分比 |
| --- | --- |
| 总计 | 100% |
| MSIE 6.0 | 55.68% |
| MSIE 7.0 | 23.1% |
| Firefox/2.0 | 7.72% |
| Maxthon | 7.36% |
| TencentTraveler | 4.09% |

从这个统计数字来看，IE6的用户还高达55%的份额，比其他所有浏览器用户量的总和还要多，由于微软的强制升级，这个数字在未来几天可能会发生巨大的变化，IE7的用户可能会首次超过IE6的用户。

微软表示，此举是出于对目前安全问题的关注，此次升级不再需要对用户的Windows进行正版验证。
