在Z-Blog系统中，将文章[锁定](https://www.williamlong.info/archives/1370.html)后会无法出现评论框，但无法实现类似WordPress的一个功能，就是针对超过30天的文章自动关闭评论。

这个功能主要是为了防止垃圾评论设置的，对于更新较慢的博客尤为适合。要想让这个功能在Z-Blog中实现，修改方法如下：

在 c\_system\_lib.asp 中找到Function Export\_CommentPost()函数，在函数开头增加一行：

If DateDiff("d",PostTime,now())>30 Then Exit Function

这样就能实现30天之前的文章停止评论，修改完成之后需要进行一次文件重建的操作。

由于Z-Blog的文件重建系统有点问题，对于评论多于400条的文章往往无法重建文章，我们可以使用下面的语句将评论数多余400条文章的评论自动关闭。

If CommNums>400 Then Exit Function

此外，将文章锁定后，文章评论也一起删除的方法是，找到Export\_CMTandTB函数，在函数里增加一行：

If Level = 3 Then Exit Function
