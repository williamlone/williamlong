今年五月份，我曾经写了一篇《[我的社会化网络统计](https://www.williamlong.info/archives/1799.html)》，详细记录了当时我在各个社会化平台的个人统计信息，现在大半年过去了，这里再次对这些数据进行一些统计。

五月份的这些社会化服务中，除了“饭否”外，其他均还存在，不过Twitter、Facebook、FriendFeed三个服务无法从直接国内访问。新浪微博[我在八月份才注册](https://www.williamlong.info/weibo/archives/348.html)，因此实际增长数有些低估，即便如此也排名第二。

按照我的好友数目增长情况，我得出了下面这个表格，以我的好友（跟随者）的增长数量进行了排序。

|  |  |  |  |
| --- | --- | --- | --- |
| 社会化服务 | 五月好友数 | 目前好友数 | 增长量 |
| Twitter | 1567 | 8783 | 7216 |
| 新浪微博 | 0 | 2960 | 2960 |
| Google Reader | 606 | 1732 | 1126 |
| 嘀咕 | 337 | 1104 | 767 |
| 开心 | 243 | 924 | 681 |
| FriendFeed | 1337 | 1944 | 607 |
| Facebook | 783 | 1268 | 485 |
| 豆瓣 | 228 | 369 | 141 |
| Orkut | 648 | 723 | 75 |
| Delicious | 206 | 224 | 18 |
| Flickr | 55 | 71 | 16 |
| 饭否 | 900 |  | -900 |

从上表中，我可以得出以下几个分析评论。

1、微博客用户更易于跟随和关注，比SNS更易于传播。微博客也具有排他性，通常某个圈子内成功的微博客只有一个。

2、Facebook、开心等应用的跟随者少的一个重要原因，是因为需要确认才能成为好友。

3、被Yahoo收购的Web 2.0应用没有好下场，Delicious和Flickr的发展处于停滞状态。

4、Orkut已经输给Facebook了。

5、被大公司收购的Web 2.0服务普遍发展不好。

6、以网站为核心的Web 2.0服务一旦被封，其在国内的发展就停滞不前。

7、去中心化的微博客服务（如Twitter）很难被封。

8、目前SNS的热潮已经过去，微博客的发展方兴未艾。
