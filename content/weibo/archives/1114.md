Wordpress有一个很强的主题：Suffusion，其自定义配置很强大，这里以Suffusion 4.0.2为例说明一下其自定义设置的功能。

页面宽度：Layouts - Default Sidebar Layout - Fixed width settings - Overall Page Width

顶部导航按钮：Other Graphical Elements - Navigation Bar Below Header - Categories in Navigation Bar - Show the top level categories in the navigation bar and their sub-pages in drop-downs

网站图标：Other Graphical Elements - Favicons

网站颜色：Skinning - Theme selection

网站左上部LOGO：Skinning - Header - Header Foreground Image

统计分析代码：Back-end - Analytics

网站背景色（外框）：Skinning - Body Background

网站背景色（内框）：Skinning - Main Wrapper

页顶边距：Skinning - Header - Empty Space Between Top of Page and Header

总的修改选项，需要将各个栏目的Theme styles 修改为 Custom styles，否则调整不起作用。

首页摘要显示：Layouts - Front / Blog Page Views

摘要字数：Layouts - Layout: Excerpt / List / Tile / Mosaic / Full - Number of words in auto-generated excerpts

发布信息格式： Other Graphical Elements - Post and Page Bylines
