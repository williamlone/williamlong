消息称微软下一代 Windows 图形 API DirectX 12 将不支持 Windows 7。微软此前曾宣布 DirectX 12 将于 2015 年某个时候随同 Windows 10 一同发布。对 Windows 7 的主流支持将于 2015 年 1 月结束。
