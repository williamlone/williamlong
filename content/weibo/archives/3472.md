打开World of Warcraft\\_classic\_(\_retail\_是正式服)\WTF\Config.wtf(用文本方式打开，添加下面命令到文本最下面)

SET overrideArchive "0" 反和谐 (除图标外，血，颜色，模型等等)

SET profanityFilter "0" 关文字过滤

保存退出。

好了，你的魔兽世界已经是永久反和谐版本了，不会因为联网被重置。

也可游戏内聊天窗口输入(重登可能会失效，建议手动添加)

/console SET overrideArchive "0"

/console SET profanityFilter "0"

一些护眼功能，游戏内聊天窗口输入

/console ffxGlow 0 关泛光效果，光线反射(关闭会使色彩变暗，建议不关)

/console ffxDeath 0 关死亡效果，和活着一样

/console weatherDensity 0 天气效果0-3档由弱变强(一般怀旧服用于屏蔽暴雨，风沙，雾气)
